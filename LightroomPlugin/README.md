# Reality Processor – Lightroom Classic bridge

## Instalace (jen jednou)

1. Otevři Adobe Lightroom Classic.
2. File → Plug-in Manager…
3. Klikni Add.
4. Vyber složku:
   `RealityProcessor_v1/LightroomPlugin/RealityProcessor.lrplugin`
5. Plugin musí svítit jako Installed and running.

## Test v0.7

1. V Reality Processor načti zakázku a klikni Analyzovat.
2. Klikni Připravit Lightroom HDR.
3. V Lightroom Classic zvol Library → Plug-in Extras → Reality Processor: Načíst HDR frontu.
4. Plugin přidá zdrojové RAWy do aktuálního katalogu (pokud tam ještě nejsou) a vybere první HDR sérii.

Další krok bude automatické spuštění Photo → Photo Merge → HDR a průchod všech sérií bez ručního klikání.
